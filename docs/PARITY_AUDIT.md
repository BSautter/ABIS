## Cross-cutting root causes (read this first)

Several "surfaces" fail for the **same** underlying missing primitive. Fix these once and dozens of individual gaps close:

1. **Per-shape geometry primitive (11 shape dimension tables).** Rectangle / circle / chevron / fender / parallelogram / trapezoid / L- & R-trapezoid / reinforcement / liftgate / x1shape. It threads through order entry, the part master, the piece-weight calculator, invoice spec strings, dimension-check QC tolerances, the DAS job sheet, and the stacker board. Greenfield stores only the shape *name* (`sheet_type`) and drops every dimension. This one gap appears independently in 5 surfaces.
2. **No document/print/output layer at all.** Invoices, quotes, packing lists, BOLs / combi-forms, skid & scrap tags, coil ZPL/CPCL labels, transfer certificates, and virtually every report have **no** greenfield producer. The modern stack can record data but cannot emit a single physical document.
3. **No EDI engine.** Generation (861/870/846/856/863), VAN transport (Inovis/GXS SFTP), inbound ingestion, and 997 reconciliation are all absent; `/edi` is a read-only ledger. This is the single largest functional block. **Constraint:** per the no-live-firing rule it must be single-owner — the legacy crontab on db01 stays the sole owner until a controlled cutover, so this is a re-home problem, not a green-field-and-run problem.
4. **No live shop-floor (DAS) capability.** The defining feature — real-time OPC DA/DCOM tag binding driving line state, counters, efficiency, and the operator workflow — is entirely absent; the modern "console" is a manual web form. Blocked architecturally by Classic OPC DA needing an edge/UA bridge.
5. **No handheld/RF scanner surface.** The Perl CGI coil-receiving station (scan → resolve/mint ABC → print label) has no greenfield home; all ~35 greenfield pages are desktop-oriented.
6. **Feature-gate enforcement wired to admin only.** The catalog and gate exist but are enforced on just 7 security-admin writes; every other domain endpoint is auth-only. This is the biggest security-parity hole.

1. **Shape geometry primitive** — model + read/write the 11 shape dimension tables once, then consume it in order entry, part master, piece-weight calc, invoice spec, dimension-QC tolerances, the DAS job sheet, and the stacker board. (Closes gaps across §1, §3, §4, §5.)
2. **Document / print engine** — a shared output service for invoices, quotes, packing lists / BOLs / combi-forms, skid & scrap tags, coil ZPL/CPCL labels, and transfer certificates. Nothing physical comes out of the system today.
3. **Live DAS data acquisition** — the edge/UA-to-Classic-DA bridge, `LINE_CURRENT_STATUS` line board, current-coil binding, shift/coil lifecycle (SHIFT_COIL), and the Operation Panel workflow. The defining capability of the shop floor; currently absent.
4. **Handheld scanner coil-receiving station** — the RF page, the `INBOUND_COIL_STATUS` / `BARCODE_STRING` model, single-scan mint, QR capture, and network Zebra printing. An entire mandated surface with zero greenfield presence.
5. **EDI engine, single-owner** — generation (861/870/846/856/863), VAN transport, inbound ingestion, and 997 reconciliation. Largest functional block; must be delivered as a controlled cutover under one owner per the no-live-firing rule, not a parallel firing path.
6. **App-wide feature-gate enforcement** — wire the existing gate to every domain endpoint (today: 7 admin writes only). Highest-value security fix and low effort relative to impact.

**P1 — Core business writes & workflows (currently read-only or hollow):**

7. Quote authoring/editing + the real pricing/cost model (CirclePro job cost + $/lb; SheetPro), and quote save/print/email.
8. Invoice document generation + save (number/date) + print, and the rejected-coil billed-weight rule.
9. Order editing/copy in-UI, customer-coil assignment, and the order-entry part picker.
10. Part revisions, routing sequences, delete, copy, and obsolete-in-use guard.
11. Customer master full field coverage + EDI/behavior flags + delete.
12. Packing-list line items + shipment EDI-trigger fields (prerequisite for the 856).
13. Recovery scrap-worksheet write + setup + the report suite; 863 test-result write + Instron import.
14. QA hold workflow (+ COIL_TRACK_QA) and dimension-check tolerance validation (the actual quality gate).
15. Warehouse/skid CRUD, scrap-skid lifecycle, and correct coil-ownership-transfer mint semantics (+ status-12 setting).
16. Security lifecycle: delete/edit users & groups, admin password reset (or explicit OIDC decision).

**P2 — Operational depth, scheduling & analytics:**

17. Admin subsystems #6 scheduler/cron-import, #7 service console, #8 EDI admin/config UI.
18. Downtime cause taxonomy (DT_INSTANCE_DETAIL) + automatic downtime capture + operator prompts.
19. Reports parity — uptime, downtime pivots, weekly/alphabetical production + Excel, maintenance/PM, scheduled recovery/inventory.
20. OPC log collector/edge bridge; serial scale/gauge acquisition; stacker automation.

**P3 — Nice-to-haves and superseded items:** sales calendar/catalog/preferences; sanity warnings (received-date, feed-length nag); reprint pickers & archived-BOL browsers; account-status checkboxes (were display-only); scanner error-email (superseded by structured observability).

### Honest severity notes for the team
- **Two P0 items are architecturally gated, not just unwritten:** live DAS (Classic OPC DA/DCOM needs an edge bridge) and the EDI engine (no-live-firing → must be a single-owner cutover). Budget these as programs, not tickets.
- **"Read-only viewer" masquerades as coverage** in several places — EDI, OPC log, recovery/quality lookups, warehouse, sketches. The data model or a GET exists, so a surface can look "done" while the entire write/workflow half is missing. The partials are frequently more dangerous than the missings because they invite that assumption.
- **Silent-correctness risks** (no crash, wrong number): rejected-coil billed weight summed naively in the browser; dimension-check `in_spec` stored without validation; edge-trim tolerance saved out-of-range with no gate. These can bill or ship wrong material and should be treated above their apparent size.
